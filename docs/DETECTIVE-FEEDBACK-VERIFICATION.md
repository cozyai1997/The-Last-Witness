## 실제 검사와 범위

- 최종 전체 자동 검사 **112/112 통과**를 확인했다. 실행은 약 22초가 걸렸으며 실패·취소·건너뛰기는 없었다. 처음 확인한 109개 검사에 채팅·전송 중 타이핑 보존, 개인 안내의 창 전환 보호, 타이핑 중 다른 접속에서 받은 검증 결과 반영 검사를 추가한 결과다.
- UI 검사 **22/22 통과**에는 기존 인증·연습·2~6인 5라운드 전체 진행과 이번 피드백의 흐름 검사 10개가 포함된다. 새 흐름 검사만 따로 실행한 결과도 **10/10 통과**했다.
- 개인정보 보호 검사와 타이핑 도중 검증 결과 변경 검사는 각각 수정 전 실패를 재현했고, 수정 후 같은 검사에서 통과했다. 개인 안내를 가린 뒤 다시 초점을 받는 흐름, 취소한 이전 타이핑 콜백의 영향 차단, 최신 검증 결과의 빨간 테두리 반영을 확인했다.
- UI 검사는 실제 게임 서비스와 UI 스크립트를 최소 DOM에서 연결한다. 타이핑은 완료·취소 시점을 제어하는 모형을 사용하여 느린 사람의 화면에 다음 동기화가 도착하는 상황을 재현한다. 이 검사가 화면의 실제 색상·글꼴·터치 동작을 측정하지는 않는다.
- 서버 검사는 공식 증거의 진실성, 역할별 응답 제한, 공개·개인 응답 분리, 기회 소모, 기존 사건 보존을 확인한다. 새 단서 배분으로 이미 진행 중인 이전 규칙 사건을 다시 배분하거나 정답을 바꾸지 않는다.

## 규칙 해석과 남은 선택

질문 필터는 같은 항목을 계속 묻는 일을 줄인다. 다섯 항목 중 탐정이 처음 아는 두 항목을 제외하면 새 질문은 최대 세 항목이다. 나머지 라운드는 기록 확인·과거 진술 검증·수사 넘기기로 끝낼 수 있으며, 최종 고발까지 다섯 라운드라는 진행은 유지한다.

현장 감식은 질문 필터와 목적이 다르다. 이미 참값을 아는 항목은 제외하되, 미검증 답변·모름·과거 은폐로 끝난 항목의 진실을 확인하는 데 남은 공용 키트 한 개를 쓸 수 있다. 질문 이력 때문에 이 검증 경로까지 없애지는 않는다.

공개 사건판의 자동 후보 수는 공개 정보로 계산한다. 탐정의 고발 창에서만 자신의 참 단서를 더한다. 수동 제외는 사용자의 추리 메모이며 참임을 서버가 보장하는 증거가 아니다. 잘못 제외한 정답은 메모 초기화로 되돌릴 수 있다.

은폐 안내의 화면 순서가 다른 기기의 진행을 정지시키지는 않는다. 읽기를 마치면 그 시점의 최신 사건 상태로 이어진다. 이미 읽은 안내의 중복 방지 기록은 사건별로 구분한다.

위 조합 수는 다섯 이진 항목이 모두 독립이고 시작 단서가 서로 다르다는 사건판 구조에서 계산한 정보량이다. 실제 사람의 승률을 측정한 수치가 아니다. 공개 전 개인 단서를 공유하는 시점, 질문 대상의 선택, 거짓말과 은폐의 선택은 플레이마다 다르다.

특히 5~6인에서는 목격자가 협력해 빠르게 단서를 공유하면 탐정이 자기 단서를 합쳐 네 항목의 실제 값을 안다. 남은 한 항목을 키트로 확인할 수 있어 수사 진영이 매우 유리해질 위험이 있다. 범인 진영의 은폐가 최대 세 번인 동안 수사는 다섯 번이므로, 적절히 협력하고 감식을 기다리는 플레이에 대해 단순히 거짓말 횟수만 유지했다고 균형이 보장되지는 않는다.

이번 변경은 요청한 탐정의 두 종류 단서를 적용하며 역할별 기회와 기존 사건을 보존한다. 추가 균형 조정은 목격자 단서의 중복 허용·공개 방식·감식 조건 등을 별도로 플레이테스트하여 결정할 대상이다. 자동 검사 통과나 컴퓨터 연습만으로 양 진영이 균형을 이룬다고 주장하지 않는다.

## 실제 브라우저 확인

로컬 `http://127.0.0.1:4184`의 실제 로그인된 2인 방을 Chrome으로 조작했다. 검증 전 답변에는 빨간 테두리가 없었으며, 의도적으로 거짓인 답변을 탐정이 검증한 뒤 테두리의 실제 색상이 `rgb(228, 89, 79)`로 바뀌고 키트가 1개에서 0개로 줄었다. 원래 답변을 지우거나 실제 값으로 바꾸지 않고 거짓 확인 상태를 표시했다.

탐정의 시작 단서는 주로 쓰는 손·조명이었고, 외투 질문을 마친 뒤 선택 항목은 착용 물품·장소 구역만 남았다. 다음 착용 물품 답변을 마친 뒤에는 장소 구역만 남았으며 가정 선택과 문구도 같은 항목에 맞춰 표시됐다. 범인에게 질문 답변 화면이 먼저 도착하고, 답변을 보낸 뒤에만 본인의 은폐 실패 안내가 나타났다. 같은 시점의 탐정에게는 실패 안내가 나타나지 않았다. 다음 라운드의 장소 구역 은폐가 성공했을 때에는 탐정의 안내 문장 타이핑이 끝나기 전 다음 진행을 막는 흐름도 확인했다. 확인 중 콘솔 경고·오류는 0건이었다. 근거는 `DETECTIVE-LOCAL-BROWSER-RESULT.json`에 저장했다.

이 브라우저 확인은 Chrome의 실제 렌더링·조작에 대한 기록이다. 모든 운영체제·모바일 실기기·브라우저에서 같은 동작을 검증했다는 뜻은 아니다.

## 운영 서버 HTTP 검증

기능 커밋 `5ad811125c10f3c6c86cb786448bbcf199aa0071`, Vercel 배포 `dpl_9TWRJqDjeWEvYLbZmFcTWWH9oRhF`의 운영 주소 <https://the-last-witness-pi.vercel.app>에서 2026-10-17 08:47:18 UTC에 검사를 완료했다. 새 테스트 계정 7개만 사용해 6인 사건의 다섯 라운드·최종 고발·재시작을 진행하고, 별도 2인 사건의 단서 자동 공개·탐정 비밀 행동 생략·2일차 고발도 확인했다. 기존 사용자의 방·계정은 검사 대상으로 사용하지 않았다.

의도한 거부 응답을 포함해 **390개 HTTP 요청이 모두 예상한 판정을 통과**했다. 요청 평균은 **628ms**, 최대는 **3,932ms**였다. 탐정의 인물 힌트 1개·현장 단서 1개, 다른 목격자 단서와의 비중복, 완료·봉쇄 질문 이력, 답변이 끝나기 전 은폐 실패 결과를 보내지 않는 조건을 확인했다. 보호에 막힌 은폐·수사 봉쇄 성공·다른 항목을 조사한 은폐 실패를 나타내는 개인 결과 필드와 누적 이력은 범인에게만 전달됐으며 공범에게도 노출되지 않았다. 공범이 준비한 은폐의 개인 결과 역시 범인에게만 전달됐다.

여섯 계정 모두 비밀번호로 다시 로그인해 기존 역할·사건·기회·질문 이력·개인 상태가 보존되고 이전 접속 토큰이 거절되는 것을 확인했다. 답변 검증은 원래 진술을 보존하면서 공식 참값을 추가하고 한 번의 키트를 소모했다. 기록은 `DETECTIVE-LIVE-HTTP-RESULT.json`에 저장했다. 같은 검사를 로컬 서버에서도 390요청으로 통과했으며 평균 502ms·최대 3,370ms였다(`DETECTIVE-LOCAL-HTTP-RESULT.json`).

이 검사는 실제 운영 API와 저장소를 사용한 여섯 참가자 세션 검사다. 여섯 대의 실제 기기를 동시에 조작한 브라우저 검사나 장시간 부하 검사, 인간 플레이 승률 측정은 포함하지 않는다. 측정한 응답 시간은 이 실행 당시 결과이며 속도 보장은 아니다. 이후 문서만 추가하는 검증 기록 커밋과 위 기능 커밋은 구분한다.

## 운영 파일과 화면 확인

운영 배포의 READY 상태와 기존 운영 주소 연결을 확인했다. HTML·JavaScript·CSS·규칙 파일 13개의 응답 내용이 위 기능 커밋과 일치했고, 배경음 MP3·OGG와 필기체 WOFF2 글꼴은 크기와 SHA-256까지 일치했다. 서버 내부 파일과 환경 파일은 공개되지 않았다. `DETECTIVE-LIVE-STATIC-RESULT.json`에 확인 시각과 결과를 기록했다.

같은 검증용 탐정 계정으로 운영 Chrome에서 로그인해 기존 4일차·역할·단서·수사 이력이 복구되는 것을 확인했다. 완료한 외투·착용 물품, 은폐로 막힌 장소 구역, 시작 기억인 손·조명이 모두 질문과 가정 목록에서 제외됐다. 질문이 없는 상태는 비활성화 안내를 표시하고 수사 넘기기와 고발 메뉴를 유지했다. 콘솔 경고·오류는 0건이었다(`DETECTIVE-LIVE-BROWSER-RESULT.json`).

로컬 Chrome에서는 3일차 은폐 성공 안내 이후 4일차로 이어지는 흐름, 소진된 질문 목록, 공식 기록 기준 인물 2명·장소 2곳만 남은 고발 창도 확인했다. 내 제외 메모에서 인물·장소를 하나씩 지운 뒤에는 각각 후보 한 개만 표시됐다. 이 메모는 브라우저별 추리 기록이며 다시 로그인한 다른 브라우저로 옮겨지지 않는다. 이번 새 화면 검사는 데스크톱 Chrome이며 모바일 실기기·Safari·Firefox 검사를 추가로 수행하지 않았다.
