# 계정 복귀·배경음악 검증 — 3.1.0

2026-10-17, 기존 3.0 게임의 규칙·이미지·FX와 플레이 중 데이터를 유지하면서 닉네임/비밀번호 계정 및 오리지널 BGM을 추가했다. 이전 버전의 검사 기록은 `ACCEPTANCE.md`에 남긴다.

## 동작

- `register`: 고유 닉네임과 8~128자 비밀번호로 계정을 만든다. 닉네임은 NFKC 정규화·대소문자 기준으로 중복을 막는다. 이메일·전화번호는 받지 않는다.
- 현재 유효한 게스트 토큰과 함께 등록하면 현재 사람의 같은 좌석 ID를 계정에 연결한다. 플레이 중 역할·사건·차례·자원과 기록을 유지한다. 닉네임만으로 과거 게스트의 자리를 가져오지 못한다.
- `login`: 닉네임과 비밀번호를 검증하고 같은 계정 ID 및 방을 복구한다. 이전 접속 토큰은 폐기하며 다른 기기에 열려 있던 접속은 다음 요청에서 로그아웃된다.
- `logout`: 접속 토큰만 폐기한다. 방에서 나가지 않으며 역할·자리·방장은 그대로 남는다. 명시적인 '방 나가기'는 자리를 반납한다.
- 계정은 서버 저장소에 지속 보관한다. 세션은 24시간 후 만료되지만 비밀번호 재로그인으로 복구된다. 방은 마지막 플레이·방 운영 행동 이후 30일간 보관하며 단순 폴링·로그인은 보관 기간을 연장하지 않는다.

## 비밀번호와 정보 보호

서버에서 고유한 난수 salt와 `scrypt(N=131072, r=8, p=1)`로 저장한다. 원문 비밀번호는 저장소·응답·행동 영수증·브라우저 저장소에 넣지 않는다. 해시 계산은 동시에 2개, 대기는 12개로 제한하며 CAS 재시도에서 해시 계산을 반복하지 않는다. IP 제한과 계정별 로그인 실패 제한을 적용한다. 계정·해시와 기존 게스트 권한을 저장 직전에 다시 확인해 동시 요청의 자리 탈취를 막는다.

서버 정보는 공개 기록과 본인의 역할만 반환한다. 계정 응답에는 ID와 닉네임만 포함한다. 저장소는 기존 비공개 Supabase 문서와 서버 비밀키로 보호된 CAS 함수를 그대로 사용하며 새로운 공개 테이블이나 정책은 만들지 않았다. 비밀번호 복구·메일 인증은 이번 범위에 포함하지 않는다.

참고: [OWASP 비밀번호 저장 지침](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html), [Vercel 함수 메모리 문서](https://vercel.com/docs/functions/configuring-functions/memory).

## 실행한 검사

- `npm test`: **57/57 통과**. 계정 11개, UI 9개, 온라인 서비스 18개, 기존 게임 엔진 19개.
- `npm run test:security`: **20/20 통과**. 여섯 참가자에게 보내는 단계별 정보와 재로그인 후 동일 게임 상태를 검사한다.
- `npm run test:auth-review`: 독립적인 경합 검사 **5/5 통과**. 해시 계산 중 다른 행동, 같은 게스트의 중복 등록, 등록 중 로그아웃, 새 로그인 후 과거 토큰의 지연 요청, 6명 세션 만료 후 복귀를 검사한다. `AUTH-SECURITY-REVIEW.json`에 기록했다.
- 실제 Supabase 연결 로컬 HTTP: **6인·5라운드·308개 요청 통과**, 평균 518ms·최대 2715ms. 3라운드에 전원 비밀번호 재로그인, 과거 토큰 거부, 로그아웃 후 자리 복귀, 최종 승리와 재시작까지 검사했다. `AUTH-LOCAL-HTTP-RESULT.json` 참조.
- 실제 Chrome에서 게임 탭을 닫고 새 탭을 열어 비밀번호로 로그인했다. 동일 방·좌석·범인 역할·1라운드와 개인 행동 차례를 확인했다. 이 검사는 로컬 HTTP + 실제 Supabase를 사용했다.
- 390px 모바일 사건판에서 가로 넘침이 없었다. 음악 조절기는 폭 222px로 화면 안에 들어왔고 개인 정보 패널·로그인·고발 화면과 함께 사용할 수 있다. 실제 휴대전화 Safari/Firefox는 별도 미검증이다.

## 음악

오리지널 「고요한 증거 / Quiet Evidence」는 64초, D단조, 60BPM이다. 외부 음원·녹음·악기 샘플 없이 수식과 음표로 합성했다. MP3·OGG 모두 정확히 64초로 디코딩됐으며 비정상 값과 클리핑이 없었다. 생성 조건·파일 해시·반복 접합 수치는 `public/audio/manifest.json`에 있다.

Chrome에서 사용자가 재생을 눌러 재생 시간 진행, 64초 루프의 시작 구간으로 귀환, 음량 25→24%, 음소거를 확인했다. 회원가입·대기실·게임으로 화면이 바뀌어도 음악은 유지됐다. 새 탭은 자동 재생하지 않으며 음량·음소거만 기억한다. 브라우저 재생 확인은 사람의 음악 감상 평가와 구분한다. 제작 소스는 `scripts/generate-bgm.py`, 사용법은 `BGM.md`에 있다.

## 배포 확인

운영 배포 후 실제 주소에서 다시 검사하고 결과를 별도 JSON에 기록한다. 빌드 성공만으로 운영 접속·복귀가 확인됐다고 간주하지 않는다. 계정·게임 상태 초기화나 기존 방 삭제는 수행하지 않는다.
