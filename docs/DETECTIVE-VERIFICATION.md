# 탐정 질문·판별 개편 검증 — 4.2

## 새 사건의 계약

- 탐정의 하루 공식 수사 선택을 없앴다. 매일 질문 한 번 또는 질문 넘김으로 하루의 질문을 마감한다.
- 과거 진술·방금 답변 판별은 사건 전체 두 번을 공유한다. 질문 전과 답변 검토 중에 쓸 수 있으며 질문 기회와 하루를 끝내지 않는다. 다른 참가자의 답변 대기 중에는 쓸 수 없다.
- 시작 확답은 성별·손·근무·권한·구역·진입로·카메라·도구·시간, 전체 아홉 항목 중 서로 다른 두 항목이다.
- 용의자는 다른 닉네임과 같은 대상 목록에 남는다. 정체 회복·개인 단서와 관계없이 공식 답변은 null이며, 공개 표기는 모든 null 응답과 같은 ‘기억 불명’이다. 용의자의 기억 회복과 봉인 제보는 유지한다.
- 공식 원본 조사 행동은 새 사건에서 제공하지 않는다. 공개 연결 자료·카드·기존 기록은 계속 읽을 수 있다.
- 이미 판별한 진술, 다른 화자의 같은 확정 주장, 시작 확답·기존 증거·공개 연결표를 대조해 진위가 이미 결정된 주장은 판별 대상에서 제외하고 서버도 거절한다. 실패 요청은 판별권과 질문 기회를 쓰지 않는다.

## 생성과 정보 경계

모든 신규 온라인·연습 사건이 `detectiveVersion: 2`를 명시한다. 저장 사건에 이 표시가 없으면 이전 계약을 유지하며 정답·역할·자원을 재배정하지 않는다. 규칙 3 사건도 그대로 보존한다.

새 연결표는 실제 정답 경로와 초기 확답에 맞는 대체 경로를 함께 생성한다. 탐정이 자기 인물의 결백을 대조한 뒤에도 진범 인물 후보가 최소 두 명 남는다. 두 시작 답만으로 자동으로 게임이 끝나는 사건을 방지한다. 이것은 이후 질문·증언으로 후보가 한 명으로 줄어드는 것을 막는 조건은 아니다.

엔진 자동 검사는 500개 시드에서 모든 36개 단서 조합을 확인했고, 출입 권한이 맞는 인물·장소 108개 강제 조합과 마지막 도구·시간 카드도 검사했다. 기존 2·4·6인 고정 시드의 전체 상태 해시는 이전과 동일하다.

## 실행한 확인

- 전체 자동 테스트 **284/284** 통과. 생성·판별·중복 필터·실제 UI 동작·온라인 서비스·인증·과거 저장·2~6인 모든 연습 역할을 포함한다.
- 보안 검사 20개, 인증 경합 검사 5개 통과. 인증 검사는 별도의 메모리 저장소에서 실행했으며 침투 테스트를 뜻하지 않는다.
- 실제 로컬 HTTP **660회** 통과: 6인, 7일, 4가지 결말, 판별 2회, 판별 후 질문 유지, 무효 요청 자원 보존, 용의자 기억 불명, 재로그인 13회, 동일 복기 24회, 공개 연결 조합 1,728개.
- 독립 검토에서 별도 AUDIT으로 현재 답변을 판별하면 화면에 미검증이 남는 경로를 발견했다. 진술 자체의 판별 상태를 우선 표시하도록 수정하고 실패→성공 회귀 검사를 추가했다.
- 독립 컴퓨터 검사 50건·4,080행동에서 7일 완주와 매 행동 후 실제 정답 후보 보존을 확인했다.
- 재현 가능한 기준 컴퓨터 정책 검사 500건·40,930행동에서 불법 행동·교착·시작 즉시 단일 인물 확정이 모두 0건이었다. 매 행동 뒤의 정답 보존을 40,430회 검사했으며 단서 항목 9개·조합 36개가 모두 출현했다. 상세는 `DETECTIVE-POLICY.json`, 실행 파일은 `tests/seven-detective-v2-policy.cjs`다.
- Chrome 실제 연습에서 질문 전송→답변 수신→거짓 판별→남은 횟수 1/2→다음 날 전환을 조작했다. 거짓 테두리 계산 색상은 `rgb(189, 101, 90)`이었다.
- 390×844와 360×640에서 질문·넘기기 버튼이 각각 높이 44px로 화면 안에 남았다. 360×640에서 버튼 아래 위치는 573px였다. 질문/판별 탭 전환과 수첩은 같은 모달에서 동작한다. 긴 기록·상세 설명은 내부 읽기 영역을 사용한다.

운영 배포 후의 요청·소스 일치 결과와 커밋·배포 ID는 사용자 제공 `DETECTIVE-RELEASE.json` 및 `DETECTIVE-PRODUCTION-HTTP.json`에 따로 기록한다. 이 문서는 로컬 검증 기록이며 배포 성공만으로 운영 동작을 대신 판정하지 않는다.

## 밸런스 의견

질문과 판별을 분리하면 과거 진술을 확인하려고 그날의 질문을 포기하는 문제가 사라진다. 두 시작 답의 범위가 넓어져 사건별 접근 순서도 달라진다. 반면 검증 2회는 범죄 진영의 공식 거짓말 2회와 같으므로 거짓말을 통한 지연이 약해질 수 있다.

현재 공식 거짓말을 할 수 있는 역할은 범인·공범이다. 따라서 거짓 판별 또는 이미 아는 사실과 모순된 공식 답변은 여전히 해당 참가자의 범죄 진영을 추정하게 한다. 질문의 동시 전송이나 이번 자원 조정만으로 이 설계 문제가 해결되지는 않는다. 또한 용의자를 반복해서 신문하면 질문만 낭비할 수 있으며, 목격자의 자발적 증언 신청을 채택하는 판단이 중요해진다.

컴퓨터 정책 실험은 입력 적법성·정보 경계·완주를 검사한다. 사람끼리의 승률·전략적 균형·재미를 입증하지 않는다. 추가 능력이나 진영별 거짓말 규칙은 이번 변경에 포함하지 않았다.

기준 정책에서 탐정 승리는 인원별 100건 중 2인 98건, 3인 74건, 4인 75건, 5인 77건, 6인 78건이었다. 2인에서 강세가 특히 커 보인다. 컴퓨터 범인은 의도적인 최적 기만 전략을 쓰지 않으므로 이 숫자를 사람 대전 승률로 해석하면 안 된다. 다음 조정 후보는 2인 전용 난이도에서 시작 확답의 공개 시점을 나누거나 범인의 은폐 기회를 조정하는 안이다. 이번 배포에는 승인한 공통 횟수를 그대로 적용했다.
