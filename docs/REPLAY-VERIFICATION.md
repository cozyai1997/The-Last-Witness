`http://127.0.0.1:4194`에서 2026-10-17 09:03:42 UTC에 검사를 완료했다. 실행 기록은 `REPLAY-LOCAL-HTTP-RESULT.json`이다. 일곱 참가자 접속을 사용해 6인 사건의 5라운드·최종 고발·재시작과 별도 2인 사건의 조기 종료를 확인했다. 의도한 거부 응답을 포함한 **390개 HTTP 요청이 모두 예상 판정을 통과**했다. 요청 평균은 **481ms**, 최대는 **3,121ms**였다. 응답 시간은 이 실행 당시의 측정값이며 속도 보장이 아니다.

## 운영 확인

운영 주소는 [마지막 목격자](https://the-last-witness-pi.vercel.app/)다. 기능 커밋과 배포를 확인한 후 같은 HTTP 시나리오 390개 요청을 재실행해 모두 통과했다. 요청 평균은 **505ms**, 최대는 **3,957ms**였다. 이 실행 당시의 측정값이며 속도 보장이 아니다. 여섯 참가자에게 동일한 종료 복기가 전달됐고 질문 4회·답변 3개·거짓 2개·검증 1회·은폐 결과 3개의 내용과 순서가 일치했다.

운영 브라우저의 별도 2인 연습에서는 첫날 은폐로 질문이 막혔으며 공식 답변 없이 다음 기록에 은폐 성공이 표시됐다. 둘째 날 실제 답변을 검증하고 셋째 날 거짓 답변을 받은 뒤, 다섯째 날 고발로 종료했다. 복기에서 질문·답변·검증·은폐 결과·마지막 고발을 선택하고 DAY 필터와 마지막 경계를 확인했다. 거짓 답변의 테두리는 실제 계산 색상 `rgb(220, 105, 86)`이며 원래 `어두운 조명` 진술과 정답 `밝은 조명`을 나란히 표시했다. 로컬·운영 모두 390×844 Chrome 에뮬레이션에서 가로 넘침 없이 세로 배치됐다. 브라우저 경고·오류는 0건이었고 기능 배포의 오류·치명 로그 조회에서도 기록이 없었다. 이는 전체 기간 무오류나 부하 시험을 뜻하지 않는다.

검증 자료와 소스만 추가한 후속 문서 커밋도 같은 기존 주소로 배포한다. 최종 소스 ZIP·해시 목록과 배포 ID는 함께 제공하는 `REPLAY-RELEASE.json`을 기준으로 확인할 수 있다.

## 호환성과 보관 범위

복기는 사건 기록을 추가해 보여 주는 기능이다. 기존 진행 중인 사건의 좌석·역할·정답·개인 단서·사용한 기회·현재 차례를 다시 배분하거나 초기화하지 않는다. 이전 사건의 복기 기록이 불완전하다는 사실과 사건 진행 자체를 복구할 수 있는지는 별개다.

온라인 복기는 현재 방의 종료된 사건에 속한다. 방장이 새 사건 준비를 하면 이전 사건 기록은 초기화되므로 먼저 복기를 읽어야 한다. 영구 사건별 목록·별도 보관함·과거 사건 내보내기는 이번 범위에 포함하지 않았다. 컴퓨터 연습은 브라우저 메모리에서만 실행되어 새로고침·연습 나가기·재시작 때 현재 기록을 잃는다.

게임의 역할 배분, 탐정의 시작 인물·현장 단서, 5라운드·수사 횟수, 감식 키트 1개, 범인 진영의 공식 거짓말 2회, 은폐·보호 기회와 승리 판정은 바꾸지 않았다. 5~6인에서 협력하는 수사 진영이 유리해지는 기존 위험도 이번 복기 추가로 해결됐다고 주장하지 않는다. 인간 플레이 승률과 별도 밸런스 조정은 이번 검증 범위가 아니다.
