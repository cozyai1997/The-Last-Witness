# 7일 사건 대본과 자료의 일관성

## 사건의 전제

비가 내리던 박물관의 폐관 후, 연구책임자 **정윤재**의 사망이 확인되었다. 그는 사건 후보 12명과 별개의 피해자다. 사건 당일 18:00부터 21:00 사이의 기록에는 관계자와 방문객 12명, 장소 12곳, 도구 12종이 등장한다. 참가자에게 배정된 인물과 배정되지 않은 인물 모두 동일한 공개 후보이며, 배정 여부는 수사 중 공개되지 않는다.

수사는 발견 장소를 범행 장소라고 단정하지 않는다. 범행 장소·도구·시각은 서버가 한 사건으로 함께 생성하고, 인물의 출입 가능 범위와 장소의 보관·시간 기록에 양립해야 한다. 공개 연결 자료는 **가능한 범위**다. 모두가 실제로 그곳에 있었거나 그 도구를 사용했다는 확정 기록이 아니다. 현장 원본도 부분 기록이며, 공식 진술은 검증 전까지 거짓일 수 있다.

**사건 당일의 15분 시간대 12개**와 **DAY-01~07의 수사일**은 서로 다르다. DAY-07까지 지난다고 범행 시각이 바뀌지 않는다. 진실과 최초 배정은 사건 생성 때 결정되고 재접속·질문·봉쇄로 바뀌지 않는다.

## 일곱 날의 장면

| 수사일 | 장면의 목적 | 대본에서 허용하는 정보 |
|---|---|---|
| DAY-01 | 사망 사건과 수사 시작, 각자의 비밀 수첩 확인 | 피해자·박물관·12개 자료·7일 수사. 진범·정답 장소·실제 시각은 말하지 않음 |
| DAY-02 | 서로 다른 부분 기억의 대조 | 같은 사건을 기억해도 관찰한 조각은 다름. 새로 얻지 않은 단서의 구체적 값은 말하지 않음 |
| DAY-03 | 진술과 원본의 구분 | 누군가의 말과 확인된 기록은 다른 근거임을 환기 |
| DAY-04 | 닮은 인물 사이의 구별 | 한두 특징의 일치가 동일 인물의 증거가 아님. 특정 두 사람이 닮았다고 공개하지 않음 |
| DAY-05 | 이전 가설의 재검토 | 아직 확인하지 않은 질문과 다른 증거 경로를 살펴보게 함 |
| DAY-06 | 독립 용의자의 제보 마감 | 마감 자체는 공통 규칙. 누가 제보했는지와 정체 진전은 공개하지 않음 |
| DAY-07 | 마지막 수사 뒤 인물 고발 | 오늘의 수사·답변 검토를 마친 뒤 인물 카드 한 명 선택. 장소·도구·시간은 연결 근거 |

시작과 매일의 문장은 필기체로 표시된다. 컴퓨터의 턴 진행이나 새 상태 수신은 재생 중인 문장을 덮어쓰지 않는다. 계속 버튼으로 장면을 마친 뒤 최신 차례의 행동 메뉴를 연다.

## 질문과 답변의 대본 원칙

- 질문은 닉네임과 현재 선택한 가정으로 작성한다. 예: “플레이어 씨, 목격한 사람은 왼손을 주로 사용했다고 보셨나요?” 질문의 가정을 정답으로 단정하지 않는다.
- 공식 답변은 실제 제출한 값 또는 미진술을 그대로 옮긴다. 범인의 거짓말은 검증 전 대본에서 거짓이라고 알려 주지 않는다.
- 검증은 제출한 진술의 참·거짓을 판정한다. 여러 값 중 실제 정답을 덧붙여 알려 주지 않는다. 검증된 거짓 진술만 빨간 테두리로 표시한다.
- 봉쇄 안내는 기록 전달이 지연되었다는 뜻이다. 기록을 훼손·변조했다거나 질문 상대가 범인이라고 암시하지 않는다. 범인 쪽의 성공·실패 안내는 본인에게만 전달한다.
- 용의자의 기억은 자기 정체 후보를 줄이는 개인 자료다. 진범을 직접 알려 주거나 타인의 무죄를 인증하는 대사가 아니다.
- 봉인 제보 접수 문장은 제출 인물과 이유를 본인에게 확인할 뿐 정오답·우열을 암시하지 않는다.

## 마지막 장면

탐정은 확정 자료와 자신의 관찰로 남은 인물의 사진 카드 중 한 명을 선택한다. 큰 사진과 이름을 다시 확인한 뒤 고발을 확정한다. 장소·도구·시간을 추가 정답 입력으로 요구하지 않는다.

고발 직후 실제 인물·장소·도구·시각과 참가자 배정이 함께 공개된다. 수사 진영과 범인 진영의 결과, 용의자의 독립 결과를 따로 표시한다. 용의자 본인의 인물이 고발되면 제보 성공보다 패배 판정이 우선한다. 그 외 정확 제보는 개인 승리, 오제보·미제보는 생존·목표 미달이다. 대본은 생존을 승리라고 바꾸어 말하지 않는다.

종료 복기는 실제 기록된 질문·공식 답변·검증·봉쇄·기억 복원·봉인 제보·고발의 순서로 읽는다. 당시 비공개였던 정보는 종료 후 공개라는 표시와 함께 설명한다. 자유 발언을 공식 증거로 승격하지 않는다.

## 검토 체크

자료 수량은 화면의 공개 카탈로그에서 가져온다. 이미지에는 실제 진범이나 범행 정답을 미리 표시하지 않는다. 생성된 시간 이미지의 장식적 시계는 판정에 사용하지 않고, 정확한 시간은 코드의 텍스트로 표시한다. 캐릭터의 직업과 당일 업무는 서로 다른 항목이며 당일 업무 분담과 출입 권한을 추리에 사용한다. 일반 출입 인물의 실제 동선은 직원 통로에 들어가지 않도록 생성한다.
