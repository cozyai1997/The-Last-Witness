# 마지막 목격자 GUI 리메이크

사용자가 제공한 세 시안과 전체 소스 변경 승인을 기준으로 진행한다. 최신 4.2 규칙, 계정 재접속, 서버 비밀 정보 경계, 이전 규칙의 진행 중 사건은 유지한다.

- 기본 화면: 짙은 청록 상황실, 황동 테두리, 익명 참가자 아바타, DAY/현재 단계/질문·검증 예산.
- 수첩: 인물·장소·도구·시간 탭, 각각 기존 12개 자료를 4열 3행으로 표시. 카드를 누르면 연결 자료와 제외 근거. 회색과 붉은 연필 X로 제외 표시.
- 장소: 박물관 설계도 배경 위 사진 카드. 실제 연결 증거는 기존 공개 자료를 사용하고 그림으로 새로운 연결 관계를 암시하지 않는다.
- 심문: 종이 재질, 필기체 타이핑, 검증 전후 상태·거짓의 붉은 테두리·확인 버튼. 기존 순서와 횟수 제한 유지.
- 탐색: 수첩·기록·내 정보·채팅 하단 메뉴, 내 행동을 여는 주요 버튼. 자동 역할 확인/질문/검토/이야기 전환 유지.
- 화면: 390×844, 360×640 및 데스크톱에서 게임 본문 스크롤 없이 12개 카드와 주요 조작 접근. 긴 상세·대본·기록은 독립 대화상자로 제공한다.
- 접근성: 텍스트 이름, 키보드 초점, 감소된 모션 설정, 닫기, 모바일 안전 영역. 공개 아바타에 배정된 비밀 인물을 사용하지 않는다.
- 자산: GPT 생성 배경 재질 원본과 정확한 프롬프트·해시, 최적화 WebP 매핑, 일관된 SVG 아이콘. 기존 인물과 사진 매핑 보존.

실제 브라우저에서 연습과 온라인 흐름을 검증한 뒤 GitHub 커밋과 Vercel 배포 및 운영 확인까지 수행한다.
