# GUI 복구 4.3.1

사용자 피드백에 따라 4.3의 카드 사진과 여러 화면의 배치를 다시 점검했다. 이전의 본문 넘침 검사만으로 사진 가독성과 상세 창 사용성을 충분히 검증하지 못했다.

## 원인과 변경

- 원본 초상은 선명했다. 정사각형 아틀라스를 화면마다 다른 가로·세로 배경 배율로 표시하면서 왜곡되었고, 작은 사진 영역이 얼굴 윗부분과 턱을 잘랐다. 48개 자료를 원래 셀 좌표로 자르는 SVG 뷰포트와 비율 유지 렌더러로 통일했다. 셀을 먼저 잘라 여백에 이웃 사진이 보이지 않게 했다. 인물 배정과 사진 매핑은 유지했다.
- 중첩된 GUI CSS를 정리했다. 모바일 메인에는 12개 카드와 주요 조작을 유지하고 중복 제목·도구는 수첩 창에서 제공한다. 이름은 최소 12px, 주요 터치 조작은 44px 이상이다. 상세 자료·개인 수첩·규칙·복기는 읽기 쉬운 문서로 스크롤한다.
- 질문 입력은 실제 계산된 16px·48px 높이로 확인했다. 작은 화면의 4열 답변을 한 열로 바꾸고, 상세 창 안에서 다시 스크롤하는 영역을 정리했다. 닫기 헤더가 문서에 덮이지 않게 했다.
- 결과의 역할 설명은 읽을 수 있는 크기로 표시하고, 복기·전체 기록·재시작·나가기 네 조작은 하단에 고정했다.
- 숨긴 지도와 닫힌 상세 항목의 버튼을 키보드 순환에서 제외하고, 표시된 summary와 현재 유효한 조작으로 포커스를 옮긴다.
- 공개 답변·스토리 타이핑 도중 창을 벗어나면 취소된 문장과 비활성 버튼만 남던 문제를 수정했다. 공개 문장은 정상 완료 경로를 거치고, 개인 정보 창의 가림 동작은 유지한다. 개인 화면 가림에 의한 동시 재렌더 경합도 회귀 검사한다.

## 확인 범위

Edge에서 360×640, 390×844, 1440×900, 844×390 뷰포트로 확인했다. 메인 12개 카드와 하단 조작은 화면 안에 표시되었으며 카드 중심의 실제 히트 테스트를 확인했다. 확대 사진, 개인 정보, 질문 입력, 답변 검토, 지도·도구·시간 탭, 채팅 입력·전송과 줄어든 높이 390×400의 채팅 조작을 확인했다. 뷰포트 변경은 물리 모바일 기기와 실제 소프트 키보드 검증을 대신하지 않는다.

로컬 연습에서 6인 탐정으로 DAY 1~7의 질문, 봉쇄·기억 불명, 공식 답변 검증으로 판별 2→1, 최종 인물 카드 선택·확정, 범인 진영과 독립 용의자의 동시 승리, 날짜별 복기와 재시작을 확인했다. 결과의 고정 버튼 네 개는 52px 높이·13px 글자로 실제 클릭 영역을 확인했다. 최신 코드에서 이야기 타이핑 중 다른 탭으로 전환해도 전체 문장과 계속 버튼이 정상 표시되는 것도 확인했다.

새 회귀 검사는 네이티브 아틀라스 좌표·클리핑, 숨긴 조작의 키보드 포커스, 창 전환 중 공개 문장·버튼 복구를 다룬다. 키보드·창 전환 검사는 수정 전 실패와 수정 후 통과를 각각 확인했다. CSS 배치와 이미지 선명도는 Node DOM 모형의 검사 결과와 구분해 실제 브라우저로 확인했다.

최신 소스의 `npm test`는 307/307 통과했다. 빌드, 격리 저장소의 보안 검사 20개, 인증 경합·정보 투영 검사 5개도 통과했다. 실행 로그는 함께 제공하는 `outputs/gui-repair`에 있다.

게임 엔진·API·저장소·규칙 데이터는 변경하지 않았다. 사용자 방이나 배정을 초기화하지 않는다. 이전의 6인 7일 운영 API 검증을 이번 GUI의 새 실시간 다중 사용자 검증으로 표현하지 않는다. 배포 커밋·Vercel 상태·운영 화면 확인은 배포 후 제공하는 `outputs/gui-repair` 기록에 별도로 보관한다.
