# 오리지널 배경음악 — 고요한 증거

**Quiet Evidence / 고요한 증거**는 마지막 목격자에 맞춰 만든 64초 길이의 오리지널 반복 음악이다. D단조, 60BPM, 16마디로 구성했다. 부드러운 펠트 피아노를 닮은 음색, 느리게 겹치는 어두운 패드, 낮은 맥박과 옅은 질감으로 대화를 방해하지 않는 분위기를 목표로 했다. 목소리·급격한 충격음·점프 스케어는 넣지 않았다.

외부 음원이나 녹음, 악기 샘플을 가져오지 않았다. 음표·화성·배음을 직접 정하고 수식과 고정 시드의 잡음으로 합성한 음악이다. 음악 생성 서비스의 결과를 가져온 파일이 아니며, 곡의 생성 소스도 함께 제공한다.

## 파일

| 파일 | 용도 | 길이 | 크기 |
|---|---|---:|---:|
| `public/audio/witness-noir-loop.mp3` | 기본 웹 재생, MP3 160kbps | 64초 | 1,281,166바이트 |
| `public/audio/witness-noir-loop.ogg` | 보조 재생, Ogg Opus 112kbps | 64초 | 950,865바이트 |
| 별도 전달 `last-witness-noir-bgm.wav` | 다운로드용 WAV 원본 | 64초 | 11,289,644바이트 |
| `public/audio/manifest.json` | 생성 조건·파일 해시·수치 검사 | — | 텍스트 |

WAV는 44,100Hz·16비트·스테레오다. 웹 배포에는 MP3와 OGG만 사용하며 큰 WAV 원본은 배포 폴더에 포함하지 않는다.

## 작곡과 반복 처리

두 마디마다 `Dm(add9) → Bbmaj7 → Gm9 → A7sus4 → Dm(add9)/F → Bbmaj7 → Em7b5 → A7(b9)`로 움직인다. 피아노는 한 마디에 주선율 1~2음과 작은 보조음을 두어 여백을 남겼다. 저음은 강한 드럼 대신 둥근 음의 호흡으로 처리했다.

모든 음과 패드, 잔향을 64초 길이의 원형 버퍼에 배치했다. 마지막에 남은 소리는 시작 구간으로 이어지고, 배경 질감도 주기적으로 생성한다. 곡 전체를 끝에서 무음으로 줄였다 다시 시작하는 방식은 사용하지 않았다. 브라우저에서는 `audio.loop = true`로 반복한다.

## 음악 조절기

`public/bgm.js`는 문서 준비 후 한 번만 초기화한다. 화면이 다시 그려지는 `#app` 밖의 `body`에 작은 조절기를 붙여 로비·게임·결과 화면에서 유지한다. 휴대전화에서는 음량 부분을 접고 펼칠 수 있고, 화면 하단 여유를 확보한다.

- 처음에는 **일시정지 상태**다. 사용자가 재생을 눌러야 시작한다. 오디오에는 `preload="none"`을 지정했다.
- 기본 음량은 **25%**다. 약 550ms 동안 부드럽게 켜지고, 일시정지는 약 180ms 동안 줄인 뒤 멈춘다.
- 음량과 음소거만 `last-witness-bgm-v1` 로컬 저장소 키에 보관한다. 재생 여부·게임 역할·로그인 정보는 보관하지 않는다. 새 방문이나 로그인으로 자동 재생하지 않는다.
- 탭이 숨겨지면 멈춘다. 그 직전 사용자가 재생 중이었던 경우에만 돌아왔을 때 재개를 시도한다. 브라우저가 재생을 거부하면 오류를 처리하고 사용자가 다시 누르도록 안내한다.
- 재생·일시정지·음소거 버튼은 기본 키보드 조작을 지원하고 한국어 접근성 이름을 갖는다. 음량 슬라이더는 방향키로 조절한다. 채팅 입력을 가로채는 전역 단축키는 두지 않았다.

## 연동 API

`window.WitnessBGM`은 아래 기능을 제공한다. `play`, `pause`, `toggle`은 Promise를 반환하며 재생 실패를 처리해 처리되지 않은 오류를 남기지 않는다.

```js
WitnessBGM.init();            // 여러 번 호출해도 조절기를 추가하지 않음
await WitnessBGM.play();     // 사용자 동작에서 호출
await WitnessBGM.pause();
await WitnessBGM.toggle();
WitnessBGM.setVolume(0.25);  // 0~1
WitnessBGM.setMuted(true);
WitnessBGM.unmute();
WitnessBGM.getState();
```

상태에는 `initialized`, `playing`, `loading`, `volume`, `muted`, `hidden`, `duration`, `currentTime`, `source`, `error`만 포함한다. 상태 변경은 `window`의 `witness:bgm-change` 이벤트에서도 받을 수 있다. 음악 외의 게임 비밀이나 계정 정보는 포함하지 않는다.

오디오 요소는 `#witness-bgm-audio`, 조절기는 `#witness-bgm`이다. 기본 파일은 MP3이며 OGG를 보조 소스로 제공한다. 브라우저의 사용자 동작·자동 재생 정책을 우회하지 않는다.

## 재현

생성기는 [scripts/generate-bgm.py](../scripts/generate-bgm.py)다. Python과 NumPy, FFmpeg가 필요하다. 이번 생성에는 NumPy 2.3.5와 `imageio-ffmpeg` 0.6.0에 포함된 FFmpeg 7.1을 사용했다.

```sh
python -m pip install numpy==2.3.5 imageio-ffmpeg==0.6.0
python scripts/generate-bgm.py
```

기본 실행은 배포 파일을 `public/audio/`, WAV를 저장소 안의 `work/audio-source/`에 만든다. `--master-out`, `--download-out`, `--out-dir`, `--ffmpeg`로 경로를 지정할 수 있다. 고정 시드는 `4172026`이다. 압축기·실행 환경 차이에 따라 파일 메타데이터나 해시가 달라질 수 있으므로 실제 배포 파일의 해시는 manifest를 기준으로 확인한다.

## 실제 확인 범위

합성 원본과 압축 파일을 다시 디코딩해 검사했다.

| 검사 | WAV | MP3 | OGG |
|---|---:|---:|---:|
| 디코딩 길이 | 64.000초 | 64.000초 | 64.000초 |
| 최대 피크 | −6.662dBFS | −7.108dBFS | −6.593dBFS |
| 평균 RMS | −19.576dBFS | −20.022dBFS | −19.574dBFS |
| 클리핑 샘플 | 0 | 0 | 0 |
| NaN·무한대 | 없음 | 없음 | 없음 |

끝과 시작 사이의 샘플 차이는 각 파일의 일반적인 인접 샘플 변화 99백분위 이하였다. 압축 후에도 표본 길이는 원본과 같은 2,822,400프레임으로 확인했다. 이는 파형의 반복 접합에 대한 수치 검사이며 모든 기기에서 들리는 반복 품질을 보장하는 청음 결과는 아니다.

브라우저의 실제 재생 시작·현재 시간 증가·일시정지·음소거·탭 전환·모바일 배치는 배포 담당자가 별도 확인한다. 이 문서의 생성 검사만으로 실제 네트워크 재생 지연, 사람의 청음 평가, 모든 브라우저의 반복 정확성을 확인했다고 주장하지 않는다.
