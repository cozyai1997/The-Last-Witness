# 마지막 목격자 3.2 — 몰입형 사건 진행

사용자 피드백 16개 및 로그인 없는 컴퓨터 테스트 모드를 기존 온라인 게임에 적용한다. 계정·기존 진행 중 방과 비밀 정보 분리를 보존한다.

## 화면과 사건 흐름

- 대기실 준비 안내는 회전 아이콘이 있는 상태 배너다.
- 시작 이야기 → 봉인된 내 정보 창을 모든 참가자에게 자동 표시한다. 본인이 열면 역할·단서를 확인한다. 이후 자기 차례·공식 질문·탐정의 결과 검토 창을 자동으로 연다. 창 이탈 시 비밀 정보를 가린다. 같은 상태의 폴링은 창·필기 애니메이션을 다시 열지 않는다.
- 개인 창 왼쪽 위 수사기록 버튼과 탐정의 개인 창 안 공동수사 메뉴. 프로필 아래 거짓말·은폐·감식 자원은 마우스·키보드·터치 설명을 제공한다.
- 질문의 항목·가정값을 탐정이 선택한다. 대사는 실제 참가자의 신체 특성이 아닌 사건 속 인물을 목격한 내용을 묻는다. 항목 선택은 정답 힌트를 제공하지 않는다.
- 대상에게 필기체 질문과 합법적인 답변 선택지를 자동 표시한다. 탐정에게 답변이 같은 방식으로 도착한다. 검증은 기존 공용 감식 키트 1개를 소모한다. 검증은 질문 이후 결과 검토에서 선택할 수 있으며 추가 키트를 주지 않는다.
- 결과 확인 버튼이 서버에 확정되면 다음 날로 자동 진행한다. DAY-02 등 혈흔 글씨와 짧은 필기체 사건 이야기를 보여준다. 5라운드 결과 확인 후 최종 고발로 이동한다. 자유 토론은 모든 진행 단계에서 하단 플로팅 채팅으로 가능하다.
- 은폐로 수사가 막히면 범인을 제외한 참가자에게 문맥에 맞는 안내를 보여준다. 은폐 준비·숨은 역할 자체는 공개하지 않는다.
- 마지막에는 정답과 승리 진영을 밝히며 패배 진영 프로필을 회색으로 처리하고 승/패를 글자로도 표시한다.

## 규칙과 보존

- 신규 비밀번호 8~16자. 이미 만들어진 17~128자 비밀번호 계정은 기존 비밀번호로 계속 로그인할 수 있다.
- 새 2인 게임은 탐정의 시작 참 단서 2개를 공식 사실로 자동 기록한다. 탐정에게 같은 단서를 다시 공개하게 하지 않고 제안·탐정 개인 행동을 생략한다. 범인은 은폐/넘기기를 선택한다. 3~6인에서는 단서 공개와 항목 제안을 유지한다.
- 신규 게임에 rulesVersion:2를 붙인다. 이미 진행 중인 게임의 단서·역할·개인 행동 순서는 재배정하지 않는다.
- 기존 discussion은 결과 검토 상태로 사용한다. review는 공개 결과만 포함한다. REVIEW_RESULT audit/confirm은 탐정만 가능하다. 미검증 답변의 실제 값은 감사 전 공개하지 않는다.

## 컴퓨터 대전

2~6인, 내 역할 탐정/범인/무작위를 선택한다. 로그인과 서버 요청 없이 별도 로컬 엔진이 실행되며 내 정보만 인터페이스에 전달한다. 봇은 자기 역할에 허용된 정보와 공개 기록으로 행동한다. 온라인 인증 토큰·방은 건드리지 않는다. 연습 상태는 이 탭에서만 유지하고 재시작·종료를 제공한다.

## 구현과 확인 순서

1. 엔진·서비스·비밀번호: 권한, 검토/검증/다음 날, 2인 단순화, 자유 채팅, 기존 계정·방 호환 검사를 추가한다.
2. 별도 연습 어댑터와 2~6인 봇 진행 검사를 만든다.
3. 필기체·이야기·DAY 연출 모듈과 자원/질문/답변/채팅 UI를 통합한다.
4. 실제 Chrome에서 로그인 없이 탐정/범인 플레이, 질문 자동 도착, 감식 잔량·다음 날·마지막 승패, 모바일·키보드·동작 줄이기를 확인한다.
5. 인증·비밀 정보·엔진·UI·연습 테스트, 실제 서버 6인 5라운드 검증, 빌드 후 기존 GitHub/Vercel 대상으로 배포하고 운영 주소에서 다시 확인한다.

스토리 연출은 사건 정답과 충돌할 무기·시각·동선을 임의로 단정하지 않는다. 사람 여섯 명의 장기 밸런스·재미는 자동 검사와 구분한다.
