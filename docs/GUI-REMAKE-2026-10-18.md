# 마지막 목격자 GUI 개편 4.3 검증 기록

2026-10-18. 짙은 청록 상황실과 황동 테두리, 12개 자료 카드, 종이 심문 창으로 화면을 개편했다. GUI 패키지 메타데이터는 4.3.0이며, 게임 규칙은 기존 4.2를 유지한다. 아래 결과는 로컬 자동 검사와 명시된 브라우저 확인 범위다. 로컬 브라우저 확인을 마쳤으며 운영 배포 증거는 별도 산출물에 기록한다.

## 화면과 규칙 범위

- 새 7일 사건 화면에 DAY, 현재 단계, 익명 참가자, 질문·판별 자원, 수첩·기록·내 정보·대화 메뉴를 모았다. 인물·장소·도구·시간은 각각 기존 12개 자료를 유지하며, 선택은 금색, 공식 제외와 개인 추정 메모는 구별한다.
- 장소 배치도는 공개 자료를 여는 탐색 화면이다. 장식용 선과 배치는 실제 동선이나 새로운 연결 증거를 뜻하지 않는다. 실제 판정은 기존 공개 기록과 연결 자료를 사용한다.
- 탐정의 서로 다른 초기 참 단서 2개, 하루 질문 1회, 사건 전체 진술 판별 2회, 새 사건의 원본 조사 제외를 유지한다. 질문과 판별은 서로 다른 자원이다. S의 공식 답변은 계속 역할을 인증하지 않는 `기억 불명`이다.
- 계정 복구, 역할·관찰·제보·자원, 서버의 비밀 정보 경계를 바꾸지 않았다. 이전 5일 사건과 탐정 규칙·진행 방식 버전이 없는 기존 7일 사건은 저장된 규칙으로 이어간다.
- 게임 본문은 화면 안에 맞추고, 긴 상세 자료·기록·대본·규칙은 대화상자 안에서 스크롤한다. 결과는 요약 화면과 전체 결과 창으로 나누며, 대기실·첫 화면·이전 규칙 화면의 문서 스크롤은 유지한다.

주요 화면 파일은 `public/seven-app.js`, `public/online-app.js`, 마지막에 불러오는 `public/console-ui.css`다. `public/console-icons.js`의 18종 SVG는 `currentColor`를 사용하며, 아이콘 버튼은 텍스트 또는 접근성 이름으로 의미를 제공한다. SVG 내부를 눌러도 기존 `closest('[data-action]')` 위임 경로로 같은 행동을 실행한다.

보안·인증 검토는 격리된 테스트 저장소의 합성 사건을 대상으로 했다. 운영 침투 검사나 실제 사용자 계정 검사를 뜻하지 않는다. 자동 UI 검사는 DOM·상태·행동을 확인하며, 브라우저 배치 확인과 구별한다. 292개 전체 검사는 결과 요약 화면, 가로 화면 CSS, 이전 사건 결과 분기까지 반영한 4.3.0 소스에서 통과했다.

별도 로컬 HTTP 검사는 6인 7일 사건 4개, 총 660개 요청을 통과했다. 실제 HTTP 경로의 역할·기억·제보·재연결·최종 판정·복기 검사를 포함하며, 운영 서버 검증과는 구별한다.

## 독립 검토와 수정

- 공개 참가자 프로필은 닉네임과 공개 탐정 표시만 사용한다. 배정된 NPC 초상, 타인 역할·정체·관찰은 공개하지 않는다. 공개 카드 제외 근거는 본인의 비밀 정보가 섞이지 않게 계산한다.
- 개인 수첩·검토 창은 모달 여부와 키보드 동작을 맞췄다. 창의 배경이 채팅·음악 조작을 가로막지 않으며, 창 머리에서도 자유 토론을 열 수 있다.
- 화면과 수첩을 다시 그릴 때 초안·커서·채팅 스크롤과 행동 버튼 초점을 보존한다. 수첩 탭·배치도 전환·개인 제외 메모 변경 뒤 초점이 연결된 버튼에 남는 실제 DOM 회귀 검사를 추가했다.
- 진행 중 나가기를 서버가 거절하는 규칙에 맞춰 해당 메뉴를 숨겼다. 로그아웃 후 같은 자리로 복귀하는 동작은 유지한다.
- 새 7일 결과 화면은 요약 결과와 전체 결과·복기 창으로 나눴다. 기존 5일 사건은 별도의 `legacy-result` 분기를 사용해 긴 결과와 하단 재시작·나가기 조작을 스크롤로 읽을 수 있게 유지했다. 실제 앱 어댑터가 기존 결과→새 결과→기존 결과로 전환하는 회귀 검사를 추가했으며, 이전의 잘못된 분기를 메모리에서 재현했을 때 이 검사만 의도대로 실패하는 것도 확인했다.
- 무작위 초기 단서가 후반 질문을 모두 해결하면 선택적 거절 검사 횟수가 줄어들 수 있었다. DAY 1에 존재하지 않는 진술의 판별을 항상 거절시키고, 방 버전·게임 상태·판별·질문 자원이 그대로인지 확인하도록 HTTP 검사 도우미를 보완했다. 기존 최소 20회 기준과 엔진은 유지했다.

## 브라우저 확인 범위와 남은 확인

Edge의 390×844, 360×640 뷰포트 에뮬레이션에서 게임 본문 스크롤 없이 12개 자료 카드와 주요 조작에 접근하는 화면을 확인했다. 긴 상세 자료와 대화상자는 내부 스크롤로 읽는다. 이 결과는 물리 모바일 기기 검증이 아니다.

로컬 Edge에서 사람이 조작하는 탐정 화면으로 DAY 1~7을 진행했다. 봉쇄된 질문, 기억 불명, 실제 공식 답변, 진술 판별 후 자원 2→1, DAY 7 뒤 인물 한 명만 고르는 정확한 최종 고발과 수사 진영 승리, 사건 복기의 DAY 06 필터를 확인했다. 해당 실행의 브라우저 콘솔 오류 기록은 비어 있었다. 이는 탐정 조작 경로의 확인이며, 모든 역할을 실제 사람이 함께 진행한 검증은 아니다.

용의자도 DAY 1~7을 진행해 두 번의 기억 복원, DAY 3 봉인 제보와 생존·목표 미달 결과, 전체 결과 창과 재시작을 확인했다. 390×844, 360×640, 1440×900, 844×390에서 본문과 결과의 가로·세로 넘침이 없었다. 결과의 복기·전체 기록·재시작·나가기 버튼 높이는 모두 44px 이상이었다. 가로 화면은 도구와 카드를 좌우로 나누며, 데스크톱은 초상과 기록 정보를 나란히 표시한다. 최종 운영 커밋·Vercel 배포·실제 운영 별칭 검증은 별도 제공하는 outputs/gui-remake 산출물에 기록한다.
